使用教學：
1. 左側表格可直接點擊欄位編輯。
2. 按 Enter 可新增下一個任務。
3. 按 Tab 可移動到同一列右側欄位。
4. 拖曳排序 icon 可調整任務順序。
5. 顯示模式 icon 可切換「新列」或「接續上一列」。
6. 接續任務會與上一個新列任務顯示在同一條甘特列。
7. 同一列任務日期不可重疊。
8. 今日線只會在網頁預覽中顯示，不會出現在匯出檔案。
